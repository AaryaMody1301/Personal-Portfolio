DriftDoctor

Problem

Repair the contract.
Keep the reasoning visible.

A schema change can break a pipeline far from its cause. I built a local workflow that diagnoses dbt contract drift, applies guarded repairs, and checks the result before handing it back for review.

  • Python
  • dbt
  • DuckDB
  • Local AI
Explore DriftDoctor ↗

Illustrative demo · predetermined sample

Bring the contract back into alignment.

SCHEMAREPAIRCHECK

Sample: a renamed column has broken a contract.

Inside the implementation +

Approach · bounded by design

Repairs run in a disposable sandbox. Deterministic rules handle contract-defined changes; AI-assisted dependency resolution can select an observed candidate or abstain.

Evidence & limits

The final selective-agency run resolved all 12 frozen synthetic cases through deterministic skills. Novel structures still require escalation. A separate ambiguity demonstration is reported independently; neither establishes general repair accuracy.

03 Data provenance / Desktop engineering

OriginKeep

Problem

A file should remember
where it came from.

Downloads lose their context as they move between folders and versions. I built a desktop app and browser companion that connect file origins, content identity, and version history in a portable provenance record.

  • Tauri / Rust
  • React
  • TypeScript
  • SQLite
Explore OriginKeep ↗

Illustrative demo · predetermined sample

Every file has a story.

  1. Source research.example / report
  2. Version 1 report-v1.pdf · a91c…
  3. Version 2 report-v2.pdf · f20b…
↳   report-v2.pdf

Active: version 2 is linked to its source and earlier version.

Inside the implementation +

Approach · identity beyond the filename

SHA-256 links file bytes to SQLite provenance and portable JSON passports. Content-based checks support move and rename tracking without relying on filename guesses.

Evidence & limits · recoverable by design

Archive and restore workflows preserve local data and record lifecycle state. The 2.0 implementation is release-candidate ready; public distribution still requires clean-machine acceptance checks.
